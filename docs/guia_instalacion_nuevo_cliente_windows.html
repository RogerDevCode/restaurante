Instalación para un Nuevo Cliente y Gestión de Licencia

Procedimiento directo y sin rodeos técnicos para entregar el sistema listo para facturar, con su licencia comercial y sus datos fiscales configurados.

⚡ Mapa Visual del Despliegue en 3 Pasos

El proceso se divide estrictamente entre lo que haces en tu taller y lo que ejecutas en la máquina del cliente:

1 Paso 1: Generar la Licencia para el Cliente (en tu taller)

Antes de ir donde el cliente o enviarle el paquete, necesitas emitir su archivo de autorización digital.

  • 1
    Abre la carpeta de emisión en tu máquina

    Ve a la carpeta capip_claves_maestras/ y haz doble clic sobre el script:

    emitir_licencia_cliente.bat
  • 2
    El asistente te pedirá 4 datos en la ventana negra:

    • RIF del cliente: ej. J-50454272-5
    • Nombre comercial: ej. RESTAURANTE EL BUEN SABOR, C.A.
    • Límite de mesas: Escribe 0 para mesas ilimitadas (o pon el número si le cobraste por límite de mesas).
    • Vencimiento: Escribe PERPETUA (o pon la fecha AAAA-MM-DD si te paga mensualidad).

  • 3
    Resultado: Archivo licencia.lic creado

    El script genera automáticamente el archivo sellado criptográficamente con tu clave privada CAPIP. Guarda ese archivo licencia.lic para el cliente.

2 Paso 2: Instalar en la Computadora del Cliente (Windows 10/11)

En la computadora del restaurante donde correrá el programa:

  • 1
    Copia la carpeta ejecutable en la PC

    Copia la carpeta Restaurante_Ejecutable en el disco duro del cliente, por ejemplo en C:\Restaurante_2026\.

  • 2
    Pega el archivo licencia.lic

    Pega el archivo de licencia que generaste en el Paso 1 dentro de esa misma carpeta Restaurante_Ejecutable.

  • 3
    Ejecuta el instalador con un solo clic

    Busca el archivo instalacion_completa_un_clic.bat, hazle clic derecho y selecciona:

    🛡️ Ejecutar como administrador

    El instalador se encargará automáticamente de todo: instala MySQL 8.4 silencioso, levanta la base de datos vacía y coloca el acceso directo en el Escritorio con su ícono oficial.

  • 4
    Abre el sistema

    Haz doble clic en el ícono del Escritorio. Inicia sesión con el usuario maestro por defecto:

    Usuario: admin | Contraseña: admin

    Al entrar, verás de inmediato en la pantalla «Acerca de» el nombre del cliente registrado y el sello verde de Licencia Comercial Activa.

💡 ¿Quieres transferirle un menú de platos base sin ventas viejas?

Si el cliente quiere arrancar con el catálogo de 140 platos que ya tienes cargados (pescados, carnes, bebidas) pero con cero ventas, cero facturas y contadores desde el ticket #1, simplemente haz doble clic en eliminar_ventas_y_tickets.bat dentro de la carpeta y elige la opción [1]. Limpiará todo en 2 segundos.

3 Paso 3: Configurar los Datos Fiscales del Restaurante

No necesitas tocar código, ni abrir terminales, ni editar archivos de texto. Todo se hace directamente en la pantalla de la aplicación:

  • 1
    Entra a la ventana de Configuración

    En el menú lateral izquierdo de la aplicación, haz clic en el botón de la tuerca: ⚙️ Configuración / Ajustes.

  • 2
    Rellena los campos fiscales del cliente

    • RUC / RIF: El RIF del comercio (ej: J-50454272-5).
    • Nombre del Restaurante: El nombre que saldrá en la factura (ej: Restaurante El Buen Sabor).
    • Teléfono y Dirección: Datos de contacto para el encabezado del ticket.
    • Mensaje de pie de ticket: Frase final (ej: «¡Gracias por su visita! Vuelva pronto»).
    • Tasa Dólar: Tasa oficial BCV del día en bolívares.
    • % IVA: Alícuota aplicable (ej: 16.00).
    • Logo: Haz clic en el botón de imagen y selecciona el archivo PNG o JPG del cliente.

  • 3
    Haz clic en «Guardar»

    Los datos quedan registrados inmediatamente en la base de datos MySQL. A partir de ese segundo, cada comanda enviada a cocina y cada factura cobrada se imprime con los datos oficiales de ese restaurante.

❓ Aclaratoria: ¿El archivo .env ya no hace falta? ¿Son los datos de segundo nivel?

Esta es la respuesta clara y directa a tu duda sobre el archivo .env y la jerarquía de configuraciones:

El archivo .env NUNCA guardó los datos fiscales del negocio

El .env es únicamente la tubería técnica interna entre el programa Java y el motor MySQL. Solo contiene la contraseña de la base de datos local y el puerto 3306. El instalador de Windows lo genera solo. El cliente nunca lo ve ni tiene por qué saber que existe.

Los 3 niveles del sistema explicados sin tecnicismos:

Nivel ¿Dónde se guarda? ¿Quién lo maneja? ¿Para qué sirve?
Nivel 1: Legal
Licencia Comercial 		Archivo licencia.lic sellado con criptografía ECDSA. Tú (CAPIP Sistemas) con tu clave maestra privada. Garantiza que el software es legal, autoriza el RIF del cliente y define cuántas mesas puede abrir. El cliente no puede alterarlo.
Nivel 2: Fiscal
Datos del Restaurante 		Base de Datos MySQL (tablas config y configuracion_sistema). El Cliente / Administrador desde el botón ⚙️ Configuración. Es el corazón operativo: RIF en facturas, nombre comercial, tasa del dólar, IVA, dirección y logo. Se cambia con clics normales.
Nivel 3: Técnico
Enlace a Base de Datos 		Archivo .env oculto en la carpeta. El instalador automático (un solo clic). Permite que el archivo Restaurante.jar se comunique con el motor MySQL local en el puerto 3306. Nadie lo edita a mano.
📋 Checklist Rápido de Entrega

Marca mentalmente estos 5 puntos cuando vayas a entregar el sistema a un cliente:

✔ Llevo la carpeta Restaurante_Ejecutable completa en mi pendrive.
✔ Generé en mi taller el archivo licencia.lic con el RIF y nombre de este cliente y lo pegué dentro de la carpeta.
✔ En la PC del cliente ejecuté instalacion_completa_un_clic.bat como Administrador.
✔ Entré a ⚙️ Configuración con el cliente y coloqué su RIF, teléfono, dirección, logo y tasa BCV.
✔ Hice una comanda y cobré un ticket de prueba #1 para verificar que la tickera física imprima nítido con el nuevo membrete.
