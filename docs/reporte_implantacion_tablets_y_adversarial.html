1 Arquitectura del Sistema Implantado

Backend Embebido de Alto Rendimiento

  • Project Loom (Virtual Threads): Cada solicitud HTTP de las tablets se despacha en un hilo virtual liviano, evitando el agotamiento del thread pool bajo concurrencia masiva de salón.
  • Mampara de Contrapresión (Semaphore): Control estricto de conexiones concurrentes a la base de datos (MAX_CONEXIONES_BD_API = 10) para reservar ancho de banda JDBC prioritario a la estación de caja física Swing.
  • Idempotencia Anti-Duplicación: Cabecera Idempotency-Key cacheada en memoria. Las retransmisiones automáticas por micro-cortes Wi-Fi son absorbidas sin duplicar platos en cocina.

Frontend PWA Táctil para Tablets

  • Identificación por PIN: Teclado numérico táctil en modal para inicio de sesión instantáneo de los mesoneros sin teclados virtuales estorbosos.
  • Mapa Visual Tricromático: Mesas codificadas por estado operativo: Verde (Libre), Ámbar (Ocupada con tiempo y total), Azul (Pre-cuenta solicitada).
  • Offline-First & Cola de Resiliencia: service-worker.js para almacenamiento en caché local y sincronización automática de rondas pendientes al recuperar señal Wi-Fi.
