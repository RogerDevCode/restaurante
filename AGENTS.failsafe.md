# AGENTS.md

Build all features strictly via Red-Green-Refactor TDD—writing a failing behavioral test (covering both happy paths and failure, boundary, and cancellation cases) before any production code—and structure modules under SOLID and DRY principles using small, single-responsibility units, explicitly injected dependencies via narrow consumer-owned abstractions (interfaces/traits/protocols), and shared helpers only where genuine domain rules repeat (preferring minor local duplication over premature coupling). Handle errors natively and explicitly with zero silent swallows or generic catch-alls: fail fast on invalid boundary inputs, represent domain failures as typed/named errors for programmatic inspection, wrap propagated errors only when adding new operational context while preserving the underlying error chain, and never ignore cleanup or resource-close failures. Design every external I/O and concurrency boundary to be failsafe from the start using bounded timeouts, cancellation propagation, idempotent retries with exponential backoff and jitter, bounded concurrency/queues with leak-free lifecycle shutdown, graceful degradation or circuit breaking at unreliable external dependencies, and outermost-boundary recovery from unhandled panics or fatal exceptions. Facilitate rapid root-cause debugging by emitting structured, machine-readable DEBUG logs (carrying correlation/trace IDs and sanitized diagnostic context, never secrets or PII) at every failure, retry, fallback, and cleanup-error point—while logging ERROR exactly once at the outermost system boundary when translating failures into safe external responses, or logging locally whenever an error is absorbed in background/cleanup paths.
